How to Use

  1. Open the Chatbot tab — switch to the Chatbot tab to interact with the assistant.
  2. Ask a focused question — include the source school and target campus when possible.
    Example: "What are the transfer requirements for Computer Science from San Diego City College to UC San Diego?"
  3. Mention completed courses — to get tailored guidance, list the transfer or completed courses (e.g., "I've completed MATH 220 and CSE 110").
  4. Request format — ask for a summary, bullets, or a checklist. Example: "Summarize the required courses as bullet points."
  5. Check provenance — the assistant shows matched rules and confidence; use that to verify recommendations.
  6. Follow up — if something looks off, ask a follow-up question like "Which department or catalog year does that rule come from?"

Tips:

  • Be specific about campuses and majors for the most accurate answers.
  • When in doubt, ask the assistant to cite the agreement or give the exact rule text.
  • If the server is running in offline/demo mode, answers will be canned — you can still test the UI but not live LLM results.
